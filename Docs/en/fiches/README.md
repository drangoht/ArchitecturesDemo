## Three reflexes common to all the cheat sheets

1. **Start simple** ([Layered](00-couches.md), [Vertical Slice](05-vertical-slice.md),
   [Modular Monolith](07-monolithe-modulaire.md)); add complexity only for a real problem.
2. **Enforce the architecture** with the compiler (`internal`, project references) or an architecture test,
   otherwise it gets bypassed.
3. **Network or messages?** Idempotency, outbox, eventual consistency, compensation
   ([cross-cutting concepts](../concepts-transverses.md)).
